# ADR 0004 — The calm instrument
Decision (2026-10-18, operator): the visual system is reframed from "The Silent Ledger" to "The Calm Instrument". The violet stays the single accent and the band and status hues stay reserved for data. What changes is that the system now says what each screen must do, not only what it must not: one focal point per screen, set at display size when it is a number or a name; working content on white panels rather than on the paper ground; the session ribbon shipped where the design brief put it (client home, client record, clients ledger, end of session, report cover); a 120ms colour ease on controls; loading that holds the layout's shape; and a confirmation state at the end of issuing, signing, erasing and completing. DESIGN.md is rewritten to describe what is true now.

Unchanged by the operator's instruction: the practitioner's session screen (except its end moment), the column rules in tables that the owner asked for on 2026-09-20 (they go only if the owner approves a before-and-after), and the behaviour, wording, gating and order of consent signing.

Why: a design critique of `main` at 606c4e2d scored the console 24 of 40 on Nielsen's heuristics. The cause was not build quality (no stray colours, two weights, tokenised motion) but the rule set. It had grown as a list of prohibitions (no motion, no cards, no skeletons, no display type, a 6px dot) written to keep generated-looking design out, and nothing positive replaced what it forbade. The one bold element the brief reserved, the ribbon, had only been built inside the report editor, so the restraint had nothing to frame and read as a spreadsheet. The document had also drifted from the code: it still said "no accent", an ink primary button, a paper rail, 4px corners and a single transition, all of which had stopped being true.

History, superseded:
- 2026-09-02, "The Silent Ledger": achromatic chrome, mineral green-grey neutrals, ink primary button, hairlines for all depth, no accent.
- 2026-09-08 (`docs/SPEC/coloured-shell.md`, `docs/SPEC/harmonised-neutrals.md`): the owner asked for "a more attractive simple coloured design"; the mark's violet `#380473` became the accent, the neutrals were re-cast to the mark's hue, the ground dropped to 91.5% lightness so shadows could read, and three elevation levels replaced the flat system.
- 2026-09-12 onward: drawers became resizable; 2026-09-20 column rules in tables (owner); 2026-09-24 the client record and enrolment became full pages; corners moved to 6px as the default.
