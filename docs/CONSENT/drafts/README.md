# Drafts

Consent wording not yet approved by the practice lives here, one folder below
the wordings a household may be shown. `db/seed/consent-text.ts` files every
top-level `.md` in `docs/CONSENT` and never reads this folder, so nothing here
is filed or shown to anybody; `tests/portal/consent-drafts.test.ts` proves it
by path.

A draft says so in its front matter (`status: draft`, a version ending in
`-draft`). On approval it moves up one folder at `1.0`, `status: approved`,
with the date of the approval, and the seed's pinned tests gain its purpose.

Empty since 6 October 2026, when the practice approved the marketing consent
(`../marketing.en.md` and `../marketing.ar.md`).
